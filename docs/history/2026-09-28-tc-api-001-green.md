1. **경로 별칭**: 테스트가 `@/app/api/tickets/route`를 import하도록 바뀌어 `tsconfig.json` paths와 `jest.config.ts` moduleNameMapper에 `@/app/*` → `app/*` 추가 (`@/*`보다 먼저 매칭되도록 앞에 둠)
2. **DB 드라이버**: `pg`, `@types/pg` 설치. `@vercel/postgres`는 Neon 전용이라 로컬 PostgreSQL 접속 불가
